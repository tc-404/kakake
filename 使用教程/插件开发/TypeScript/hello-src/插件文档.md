# 你好示例（kakake-plugin-hello · TypeScript 轨）

用 TypeScript 写的最小可用插件示例：收消息、认指令、回一句话、调一个协议接口。业务逻辑与 JS 轨完全一致，区别只在于**要构建**。

> 这份文件就放在插件目录里，名字固定为 **`插件文档.md`**。控制台的插件列表会自动识别它并显示「查看说明」按钮——把自己插件的用法写在这里，比塞在代码注释里有效。
>
> 本工程里它在构建时会被 `vite.config.ts` 一起写进产物夹。

## 它能做什么

| 发送 | 机器人回复 |
| --- | --- |
| `你好` | `你好呀` |
| `帮助` | 可用指令列表 |
| `ping` | `pong` |
| `禁言 QQ号 秒数` | 群内禁言（秒数 `0` 为解除）。仅群聊，且机器人需要群管 / 禁言权限 |

## 怎么装

1. 在本工程目录执行 `npm install` → `npm run build`；
2. 把生成的 `kakake-plugin-hello/` **产物夹**（含 `package.json` / `plugin.json` / `index.mjs` / `插件文档.md`）拷到咔咔珂的 `plugins/` 目录；
3. 控制台 → 插件 → 打开「你好示例」的**总开关**；
4. 控制台 → 连接 → 选中你的 OneBot 连接 → 打开这个插件的**连接开关**（两个开关都要开）。

## 怎么改

- **改触发词或回复**：编辑 `src/index.ts` 里的 `if (text === '…')` 与 `sendReply(…, '…')`，然后**重新 `npm run build`**；
- **加一条指令**：照 `你好` 那段抄一份，换判断条件和回复文字；
- **调别的协议接口**：照 `禁言` 那段抄，换接口名和参数对象（常用接口见控制台 → 工具 → 插件开发 → 总览）；
- **加类型提示**：把示例里手写的 `Ctx` 换成宿主的 `NapCatPluginContext`（定义在宿主源码 `src/plugin/plugin.types.ts`）。

## 常见问题

- **改了代码没反应**：运行时读的是产物。改完 `src/` 必须重新 build，再覆盖产物夹。
- **机器人完全不理我**：总开关和连接开关两个都要开；到「日志」页确认有 `插件已加载`。
- **取不到文字、所有指令都失效**：去协议端把消息上报格式改成**数组（array）**，本插件只认 JSON 消息段，不认 CQ 字符串。
- **完整教程**：控制台 → 工具 → 插件开发（总览 / 野鸡 TS 开发 / 野鸡 JS 开发（ESM 版）/ 野鸡 JS 开发（CJS 版））。
