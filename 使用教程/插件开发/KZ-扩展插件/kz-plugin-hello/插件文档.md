# 本地便签板（kz-plugin-hello）

扩展插件示例：一个不绑任何连接的网页便签板。控制台插件列表点「查看说明」看到的就是这份文件。

## 怎么用

1. 把 `kz-plugin-hello` 整个文件夹放进 `plugins/`；
2. 控制台 → 插件 → 打开「本地便签板」的总开关；
3. 卡片上点「打开控制台」（或直接访问 `/plugin/kz-plugin-hello/page/admin`）；
4. 输入内容回车即可添加，点「删除」移除。

> 它不需要连接、不需要机器人登录，也不会出现在连接面板的插件列表里。

## 配置项

卡片右下角的齿轮按钮打开配置弹窗：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 面板标题 | 文本 | `便签板` | 显示在网页后台顶部 |
| 最多保留条数 | 数字 | `50` | 超出后自动丢弃最旧的 |
| 允许免登录只读 | 开关 | 关 | 打开后 `/plugin/kz-plugin-hello/api/health` 才返回数据 |

保存即时生效：本插件实现了 `plugin_get_config` / `plugin_set_config`，不会重载插件。

## 数据放在哪

```text
data/kz-plugin-hello/
  config.json   ← 配置
  notes.json    ← 便签内容
```

扩展插件没有账号层，所以只有这一份数据。卸载时勾选「同时删除数据」会把整个目录删掉。

## 接口一览

| 方法 | 地址 | 鉴权 | 作用 |
| --- | --- | --- | --- |
| GET | `/api/Plugin/ext/kz-plugin-hello/notes` | 需登录 | 读取标题与便签 |
| POST | `/api/Plugin/ext/kz-plugin-hello/notes` | 需登录 | 新增一条，body `{ "text": "…" }` |
| DELETE | `/api/Plugin/ext/kz-plugin-hello/notes/:id` | 需登录 | 删除一条 |
| GET | `/plugin/kz-plugin-hello/api/health` | 免登录 | 健康检查（受「允许免登录只读」控制） |

## 常见问题

- **卡片没有齿轮按钮**：插件未加载（总开关关着）或没有导出配置项。
- **打开后台 404**：`plugin.json` / `package.json` 的入口或 `webui/admin.html` 路径不对。
- **页面里接口 401**：没有从控制台打开页面（缺登录态）。
- **发不了消息**：扩展插件不绑连接，`ctx.actions.call` 会直接抛错，这是设计如此。
