# Telegram 你好示例（TG-plugin-hello）

最小可运行的 **Telegram Bot** 插件示例：认协议、收消息、认指令、回一句话、发图片与内联键盘、处理按钮回调、应答 Inline 查询。

> 这份文件固定命名为 **`插件文档.md`**，放在插件目录里。控制台插件列表的「查看说明」按钮渲染它——把用法写在这里比塞在代码注释里有效。

## 它能做什么

| 你发送 | 机器人回复 |
| --- | --- |
| `/start`（可带参数，如 `/start ref_123`） | 欢迎语；带参数时显示来源 |
| `/help` | 可用指令列表 |
| `/ping` | `pong` |
| `/photo` | 一张图片 + 「确认 / 取消」内联键盘 |
| `你好` | `你好呀 👋（来自 TG-plugin-hello）` |
| 点内联键盘的「确认」 | 先 ACK 回调，再回一句「收到你的确认」 |
| 任意聊天框输入 `@你的机器人 关键词` | 一条 Inline 结果（需先在 @BotFather 开 `/setinline`） |

群里的指令可以写成 `/ping@你的机器人`；插件会剥掉 `@用户名` 后缀，明确发给别的机器人的指令会忽略。

## 怎么装

1. 把整个 **`TG-plugin-hello/`** 文件夹放进咔咔珂的 `plugins/` 目录（**整夹拷，别只拷 `index.mjs`**）；
2. 确认已经添加并启用了一条 **Telegram Bot** 连接（见 [`使用教程/Telegram Bot 接入教程.md`](<../../Telegram Bot 接入教程.md>)）；
3. 控制台 → 插件 → 打开「Telegram 你好示例」的**总开关**；
4. 控制台 → 连接 → 选中你的 Telegram 连接 → 在「Telegram」页签打开这个插件的**连接开关**（两个开关都要开）；
5. 给机器人私聊发 `/start`，看日志页有没有 `插件已加载` 与 `telegram/event`。

## 目录名与协议

| 项 | 值 |
| --- | --- |
| 目录前缀 | 必须是 **`TG-plugin-`**（大小写敏感） |
| 插件 kind | `tg` |
| 归属协议 | Telegram Bot（`frameworkEnv.protocol === 'telegram'`） |
| 事件标记 | `event.telegram === true` |
| 账号隔离 | `plugins_two/<telegramBotUserId>/TG-plugin-hello/` |

## 怎么改

- **改触发词 / 回复**：编辑 `index.mjs` 里 `plugin_onmessage` 的 `if / else if` 分支；
- **加一条指令**：照 `/ping` 那段抄一份，换命令名和 `sendText(...)` 的文字；
- **调别的 Bot API 方法**：`ctx.actions.call('<方法名>', { ...原生参数 })`，方法名与参数按 [Telegram Bot API 文档](https://core.telegram.org/bots/api) 来，框架不做白名单、原样透传；
- **发消息的标准写法**：`ctx.actions.call('sendMessage', { chat_id, text })`——参数是 Bot API 原生参数（下划线命名），**不是** OneBot 的 `message` 段数组；
- **改完存盘即可**：`.mjs` 插件不用编译，回控制台插件页点「重载」就生效。

## 常见问题

- **机器人完全不理我**：总开关 + 连接开关两个都要开；目录名必须以 `TG-plugin-` 开头；到「日志」页确认有 `插件已加载`。
- **群里收不到普通消息**：Telegram **隐私模式默认开启**，群里只收 `/命令`、`@机器人` 和服务消息。到 @BotFather 用 `/setprivacy` 关闭，**关完必须把机器人移出群再重新拉进群**。
- **按钮点了转圈**：`callback_query` 必须调 `answerCallbackQuery` ACK，本例在 `plugin_onevent` 里已处理。
- **发消息报 `can't parse entities`**：别把用户文本直接拼进 `MarkdownV2`；本例不设 `parse_mode`（走连接默认，建议 `HTML`）。
- **报 429 / Too Many Requests**：触发限频（单聊约 1 条/秒、群组 20 条/分钟），按响应里的 `retry_after` 秒数退避重试。
- **Inline 查询没反应**：先在 @BotFather 发 `/setinline` 开启 Inline Mode。
