# 插件开发（基础）

这份教程教你写**最简单**的 OneBot11 机器人插件：对方发**固定指令**，机器人就做对应的事；还会教一次**调用协议端接口**（以禁言为例）。

## 你要知道的三件事

1. 插件就是一个文件夹，放进咔咔珂的 `plugins/` 目录。
2. 文件夹名字必须以 `kakake-` 开头（例如 `kakake-plugin-hello`）。
3. 入口文件必须导出一个叫 `plugin_init` 的函数（框架靠它认出这是插件）；收消息还要导出 `plugin_onmessage`。

## 名词解释（教程里出现的词）

| 词 | 是什么意思 |
|----|------------|
| **OneBot11** | 一种机器人**协议约定**：消息长什么样、有哪些「接口名」、参数叫什么。咔咔珂通过连接把这些请求转给协议端（如 NapCat）。 |
| **协议端 / 协议接口** | 真正连 QQ 的那一端；接口名是字符串，例如 `send_group_msg`、`set_group_ban`。 |
| **插件** | 你写的一段逻辑；框架加载后，有人发消息就会调用你的函数。 |
| **`plugin_init`** | **插件初始化函数**：插件加载时框架调用一次，适合打日志、读配置。`plugin` = 插件，`init` = 初始化。 |
| **`plugin_onmessage`** | **收到消息时的函数**：有人发消息时框架调用。`on` = 当……时，`message` = 消息。 |
| **`ctx`** | **上下文（context）**：框架传给你的「工具箱」，里面有日志、调接口等能力。 |
| **`ctx.logger`** | 打日志用的对象；`logger.info('…')` 会在控制台「日志」页看到。 |
| **`ctx.actions`** | 调协议接口的入口；真正动手的是下面的 `call`。 |
| **`call`** | **调用**：`ctx.actions.call(接口名, 参数对象)`。第一个参数是接口名字符串，第二个是参数。 |
| **`action`** | 接口名（字符串），例如 `'set_group_ban'`。 |
| **`params`** | 这个接口需要的参数对象，键名来自 OneBot11（如 `group_id`），不是自己乱起的。 |
| **`event`** | **事件**：这一次「有人发了消息」的整包数据（谁发的、在哪个群、内容是什么……）。 |
| **`event.message`** | 消息内容，推荐是 **JSON 消息段数组**（一段一段），不是一整段 CQ 码字符串。 |
| **消息段** | 数组里的一项，形如 `{ type: 'text', data: { text: '你好' } }`。 |
| **`type`** | 这一段的类型；`'text'` 表示纯文字。 |
| **`data`** | 这一段的具体数据；文字段里常用 `data.text`。 |
| **`message_type`** | 消息场景：`'group'` = 群聊，`'private'` = 私聊。 |
| **`group_id`** | 群号（群聊才有）。 |
| **`user_id`** | QQ 号（发消息的人，或你要操作的对象）。 |
| **`send_group_msg`** | 协议接口：往**群**里发消息。 |
| **`send_private_msg`** | 协议接口：往**私聊**发消息。 |
| **`set_group_ban`** | 协议接口：群**禁言**（或解除禁言）。 |
| **`duration`** | 禁言时长，单位是**秒**；传 `0` 表示解除禁言。 |
| **`export`** | 把函数「交出去」给框架用；不 export 框架找不到。 |
| **`async` / `await`** | `async` 标记「这个函数里可能要等一等」；`await` 表示「等这一步做完再往下」。调协议接口时一般都要 `await`。 |
| **`function`** | 给一小段步骤起名字，方便反复调用。 |
| **`const` / `let`** | 声明变量；`const` 一般不再改绑定，`let` 可以改。 |
| **`if` / `===`** | `if` = 如果……就……；`===` = 两边**一模一样**才算对。 |

收消息、发消息都用 **JSON 消息段**，**不要**用 CQ 码或 `raw_message`。

## 示例里有哪些指令

| 对方发送 | 机器人做什么 |
|----------|--------------|
| `你好` | 回复 `你好呀` |
| `帮助` | 回复可用指令列表 |
| `ping` | 回复 `pong` |
| `禁言 QQ号 秒数` | 调用协议接口 `set_group_ban`（仅群聊；机器人要有群管权限）。例：`禁言 123456789 60` 禁言 60 秒；秒数为 `0` 表示解除禁言。 |

写法是：**如果对方发的正是某指令（或符合某格式），就做某事**（正向匹配），不是「不等于就拦截」。

## 怎么装、怎么测（两轨通用）

1. 选 **JavaScript**：把 `JavaScript/kakake-plugin-hello/` **整夹**拷到 `plugins/kakake-plugin-hello/`（内含 `package.json`、`plugin.json`、`index.mjs`）。  
   选 **TypeScript**：先在 `TypeScript/hello-src/` 里 `npm install` → `npm run build`，再把生成的 **`kakake-plugin-hello/` 产物夹**拷到 `plugins/kakake-plugin-hello/`。
2. 打开控制台 → **插件** → 打开这个插件的**总开关**。
3. 打开 **连接** → 选中你的 OneBot 连接 → 打开这个插件的**连接开关**（要等机器人已经登录、有 QQ 号）。
4. 分别发：`你好`、`帮助`、`ping`，看回复是否对。
5. 在**群里**试：`禁言 <目标QQ> 10`（机器人需有禁言权限；别乱禁真人，可用测试号）。
6. 也可到 **日志** 页看插件有没有打印加载成功。

## 本教程讲什么 / 不讲什么

**会讲**：收消息、按指令回复、用 `ctx.actions.call` 调协议接口（发消息 + 禁言示例）、装进去能跑。

**不讲**：插件网页后台（HTML / webui）、复杂权限体系、@ 消息段解析等进阶话题。
