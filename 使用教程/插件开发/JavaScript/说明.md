# JavaScript 轨：直接编辑 `.mjs`

不用编译。先看下面的**分步例子**代码窗（一块一块看），再复制**完整插件**文件夹装进 `plugins/`。

## 几个词（白话）

| 写法 | 人话 |
|------|------|
| `if (条件) { … }` | **如果**条件成立，**就**做大括号里的事 |
| `===` | 两边**一模一样**才算对（精准匹配） |
| `function 名字(…) { … }` | 给一小段步骤起个名字，后面可以反复调用 |
| `async` / `await` | 函数里可能要等协议返回；`await` = 等做完再往下 |
| `ctx.actions.call(接口名, 参数)` | **调协议端任意接口**的通式（发消息、禁言都是它） |
| `await sendReply(…)` | 调用「发回复」这个步骤，并等它做完 |

本教程用「如果发的是某某，就做事」；**不用**「不等于就拦下来」那种写法。  
更完整的名词表见页面上方的**前言**。

## 收消息 / 发消息：只用 JSON，不要 CQ

| 做法 | 对不对 |
|------|--------|
| 从 `event.message`（JSON 消息段数组）里取 `type: 'text'` | 推荐 |
| 发送时用 `[{ type: 'text', data: { text: '…' } }]` | 推荐 |
| 用 `raw_message` 或自己拼/拆 `[CQ:…]` 字符串 | **不要教、不要用**（不稳定，用久了容易出怪问题） |

## 指令表

| 对方发送 | 机器人做什么 |
|----------|--------------|
| `你好` | 回复 `你好呀` |
| `帮助` | 回复可用指令列表 |
| `ping` | 回复 `pong` |
| `禁言 QQ号 秒数` | 调用 `set_group_ban`（仅群聊；机器人需有管权限） |

## 两个 JSON 各干什么

| 文件 | 是干嘛的 |
|------|----------|
| `package.json` | 名字、`main` 入口、`type: module` |
| `plugin.json` | 显示名、`entry` 入口、简介（入口要和 `main` 一致，都是 `index.mjs`） |

### `package.json` 字段

| 字段 | 是干嘛的 |
|------|----------|
| `name` | 建议和文件夹名一样 |
| `version` | 版本号 |
| `type` | 固定 `"module"` |
| `main` | 入口 `index.mjs` |
| `plugin` | 控制台中文名 |
| `description` | 简介 |

### `plugin.json` 字段

| 字段 | 是干嘛的 |
|------|----------|
| `name` | 插件 ID |
| `displayName` | 中文显示名 |
| `author` / `version` | 作者 / 版本 |
| `entry` | 入口 `index.mjs` |
| `description` | 简介 |

想改触发词或回复：改完整 `index.mjs` 里对应的 `if (text === '…')` 和 `sendReply(…, '…')` 即可。  
想调别的协议接口：照分步 ⑥，把 `'set_group_ban'` 和参数对象换成对应接口即可。

## 装好怎么测

总开关开 → 连接子开关开 → 发 `你好` / `帮助` / `ping`；群里可试 `禁言 <QQ> 10`（需管权限）。
