# 你好示例（CJS 版 · kakake-plugin-hello-cjs）

最小可用的咔咔珂插件示例，**CommonJS 写法**：收消息、认指令、回一句话、调一个协议接口。

> 这份文件就放在插件目录里，名字固定为 **`插件文档.md`**。控制台的插件列表会自动识别它并显示「查看说明」按钮——把自己插件的用法写在这里，比塞在代码注释里有效。

## 它能做什么

| 发送 | 机器人回复 |
| --- | --- |
| `你好` | `你好呀` |
| `帮助` | 可用指令列表 |
| `ping` | `pong` |
| `禁言 QQ号 秒数` | 群内禁言（秒数 `0` 为解除）。仅群聊，且机器人需要群管 / 禁言权限 |

## 和 ESM 版（`kakake-plugin-hello`）的唯一区别

```js
// CJS（本插件）
async function plugin_init(ctx) { /* … */ }
module.exports = { plugin_init, plugin_onmessage };

// ESM（kakake-plugin-hello）
export async function plugin_init(ctx) { /* … */ }
export async function plugin_onmessage(ctx, event) { /* … */ }
```

效果、钩子名字、`ctx` 能力完全相同；差别只在「怎么交出函数」「怎么引入别的文件」。

## 怎么装

1. 把整个 `kakake-plugin-hello-cjs/` 文件夹放进咔咔珂的 `plugins/` 目录（**整夹拷，别只拷 `index.js`**）；
2. 控制台 → 插件 → 打开「你好示例（CJS）」的**总开关**；
3. 控制台 → 连接 → 选中你的 OneBot 连接 → 打开这个插件的**连接开关**（两个开关都要开）。

## 这个插件包为什么长这样

- **`index.js` 里用 `module.exports = { plugin_init, plugin_onmessage }`** 交出钩子，并且写成**字面量对象**。虽然宿主兼容层也认 `module.exports = 运行时拼出来的对象`，但没有必要冒这个险。
- **`package.json` 里写的是 `"type": "commonjs"`**，不写 `"type": "module"`。宿主根目录是 `"type": "module"`；插件包不表态的话，`.js` 会被 Node 当成 ES module。**宿主带了 CJS 兼容层，不表态也能跑**（入口和包内 `require` 进来的 `.js` 都会被按 CommonJS 编译），但写上 `"commonjs"` 更稳、也更好读。

## 怎么改

- **改触发词或回复**：编辑 `index.js` 里的 `if (text === '…')` 与 `sendReply(…, '…')`；
- **加一条指令**：照 `你好` 那段抄一份，换判断条件和回复文字；
- **拆成多个文件**：`const { sendReply } = require('./helper.js');` —— 相对路径的 `./` 别省、`.js` 后缀写全；
- **调别的协议接口**：照 `禁言` 那段抄，换接口名和参数对象（常用接口见控制台 → 工具 → 插件开发 → 总览）；
- **改完存盘即可**：JS 插件不用编译，回控制台插件页点「重载」就生效。

## 常见问题

- **机器人完全不理我**：总开关和连接开关两个都要开；到「日志」页确认有 `插件已加载`。
- **日志说「缺少 plugin_init」**：检查是不是写成 `exports = { … }` 了——给 `exports` 重新赋值会把引用断开，框架拿到的是空对象；要整体交出去就写 `module.exports = { … }`。
- **`Cannot find module './xxx.js'`**：`require` 的路径写错了。相对路径的 `./` 不能省、`.js` 后缀建议写全、那个文件要真的在插件目录里。
- **日志说「已按 CJS 兼容模式加载」**：入口是 CJS 写法却会被当成 ESM 解析，兼容层把它救回来了。能跑就不用管。
- **取不到文字、所有指令都失效**：去协议端把消息上报格式改成**数组（array）**，本插件只认 JSON 消息段，不认 CQ 字符串。
- **禁言没生效**：机器人不是管理员 / 群主时接口会失败，插件会把失败原因回给你。
