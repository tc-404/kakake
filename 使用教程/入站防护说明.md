# 咔咔珂 · 入站防护说明

「入站防护」是系统设置页里的一个总开关，管的是**别人主动连进来**的那一侧：
协议端上报、插件免鉴权路由、以及封禁期间的未认证连接。

- 默认：**开启**
- 影响范围：**只对外部地址生效**；本机（127.0.0.1 / ::1）与内网地址永远不受影响
- 生效方式：切换开关后**立即生效**，不需要重启

---

## 一、开启时会做什么

| 场景 | 表现 |
|---|---|
| OneBot 上报 / 事件流取流 / 反向 WS 的凭证错误 | 来自外部地址的失败会被记录；连续失败到一定次数，该来源会被临时拒绝一段时间 |
| 全局封禁进行中 | 没有配置 Access Token 的 OneBot 连接会**暂停**，直到封禁解除（本机登录一次或重启可提前解除） |
| 插件注册的免鉴权路由（`/plugin/<插件>/api/...`） | 来自外部地址的请求有每分钟上限，超过会返回 429；本机/内网不限 |

配了 Access Token 的连接不受全局封禁影响——有凭证就照常收发。

## 二、什么情况下需要关掉

- 协议端用了**动态出口 IP**（家用宽带、手机流量、云函数），换 IP 后被误判成攻击
- 插件把免鉴权路由当公开 API 用，外部调用量本来就很大（超过每分钟上限）
- 排查问题时想先排除这层干扰

关掉后上述行为全部回到旧逻辑：不记失败、不临时拒绝、不做每分钟限速、
全局封禁期间未配 token 的连接也照常工作。**登录鉴权、登录失败限速、
单 IP / 全局封禁本身不受这个开关影响**，它们始终生效。

## 三、怎么切换

1. 打开咔咔珂 Web 控制台 →「系统设置」页
2. 找到「入站防护」这一行，点最右侧的开关
3. 立即生效，配置写入 `data/config.json` 的 `inboundGuard` 字段

## 四、和另外几个开关的区别

| 开关 | 管什么 | 默认 |
|---|---|---|
| 入站防护 | 外部连进来的协议端上报、插件免鉴权路由、封禁期的未认证连接 | 开 |
| 外放 API | 框架对外提供只读概览（`/api/public`） | 关 |
| 接口代理外放 API | 框架对外提供可调用接口（`/api/v1/<短名>`） | 关 |
| 登录防护（设置页只读展示） | 控制台登录失败的计数与冷却状态，可一键解除 | 始终生效 |

前三个互相独立，可以任意组合。
