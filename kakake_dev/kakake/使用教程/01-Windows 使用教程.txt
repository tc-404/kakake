================================================================================
  咔咔珂 Kakake · Windows 使用教程（从零到能聊天）
  适用: Windows 10 / Windows 11（64 位）
  启动脚本: 项目根目录 start.bat
================================================================================

【先说清楚三件事】
  1) 咔咔珂本身不带 QQ 登录能力，它只是「机器人框架」。
     真正登录 QQ 的是 NapCat 之类的协议端，咔咔珂通过 WebSocket 和它对接。
  2) Windows 上没有 mk 脚本可用（mk 只面向 Linux 服务器和 Termux）。
     Windows 一律用 start.bat 启动。
  3) 首次启动会自动做三件事，耗时较长（视网络 3-15 分钟）：
     装后端依赖 → 构建前端界面 → 打包后端。之后再启动只要几秒。

【本机需要什么】
  · Node.js 20 或更高版本（推荐 22 LTS）
  · 能联网（要从 npm 下载依赖）
  · 硬盘剩余空间 ≥ 2 GB

--------------------------------------------------------------------------------
第 1 步：安装 Node.js
--------------------------------------------------------------------------------
1) 浏览器打开 https://nodejs.org/ ，下载 LTS 版的 Windows Installer（.msi）。
2) 双击安装，全程下一步即可。安装向导里那个
   「Automatically install the necessary tools...」的勾选框不勾也没关系。
3) 装完后按 Win+R，输入 cmd 回车，在黑框里输入：

     node -v
     npm -v

   要能看到类似 v22.20.0 和 10.9.3 的输出。

  ▸ 报错「'node' 不是内部或外部命令」或「无法将"node"项识别为...」
    原因：装完没重开命令行窗口，PATH 环境变量还是旧的。
    解决：关掉所有 cmd / PowerShell / 编辑器，重新开一个再试。
          还不行就重启电脑；仍不行则手动检查「系统属性 → 环境变量 → Path」
          里是否有 C:\Program Files\nodejs\。

  ▸ node -v 显示 v18.x.x 或更低
    原因：装的是旧版本，或者机器上有多个 Node。
    解决：卸载旧版重装 LTS。用 nvm-windows 的话执行 nvm install 22 && nvm use 22。

--------------------------------------------------------------------------------
第 2 步：把项目放到合适的目录
--------------------------------------------------------------------------------
把整个 kakake 文件夹放在一个「本地、不同步、路径不太长」的位置，例如：

     D:\kakake
     C:\Users\你的用户名\Desktop\kakake

  ▸ 不要放在 OneDrive / 坚果云 / 百度网盘同步目录里
    这些工具会在 npm 写文件时抢占句柄，报 EPERM 或 EBUSY，还会把 node_modules
    里的几万个小文件反复上传。
  ▸ 不要放在路径特别深的地方
    Windows 默认单条路径上限 260 字符，node_modules 层级深，容易报
    ENAMETOOLONG 或「文件名或扩展名太长」。
  ▸ 路径里有中文是可以的，本项目不受影响。但如果你在别的环节遇到诡异编码问题，
    换成纯英文路径可以排除这个变量。

--------------------------------------------------------------------------------
第 3 步：启动
--------------------------------------------------------------------------------
最简单的方式：进入 kakake 文件夹，双击 start.bat。

想看清报错就用命令行启动（推荐第一次这么做，窗口不会一闪而过）：

     在 kakake 文件夹地址栏输入 cmd 回车，然后：
     start.bat

  可选参数（Windows 上只有这两个，不区分大小写）：
     start.bat force      强制重新构建前端界面（改了 src/web 里的代码后用）
     start.bat verbose    保留全部安装/构建日志，排查构建失败时用
  参数可以叠加：start.bat force verbose
  注：start.sh 上还有个 nolock 参数，那是 Termux（安卓）专用的，Windows 用不到。

  ▸ PowerShell 里输入 start.bat 报「无法将 start.bat 项识别为...」
    原因：PowerShell 不从当前目录找命令。
    解决：写成  .\start.bat

  ▸ 弹出「Windows 已保护你的电脑 / SmartScreen」
    原因：脚本没有数字签名。
    解决：点「更多信息」→「仍要运行」。

  ▸ 弹出防火墙提示「是否允许 Node.js 通信」
    勾选「专用网络」再允许。只勾公用网络会导致同一 WiFi 下的手机访问不了控制台。

  ▸ 窗口输出乱码（问号或方块）
    原因：cmd 代码页不是 UTF-8。
    解决：先执行  chcp 65001  再运行 start.bat；或改用 Windows Terminal。

--------------------------------------------------------------------------------
第 4 步：首次启动会看到什么
--------------------------------------------------------------------------------
正常流程的输出顺序大致是（前面带 [Kakake] 前缀的都是启动脚本自己打的）：

     [Kakake] Installing backend dependencies (npm install)...
     ...（装依赖、构建前端、打包后端，默认安静模式只显示少量进度）
     咔咔珂 Kakake v0.4.15 启动中...
     运行环境: Windows 10.0.26200 · x64 · Node 22.20.0

默认模式下，安装/构建真的执行过时，启动服务前会清一次屏，
控制台从框架自己的日志开始，看起来更干净。想保留全过程就加 verbose。

最后几行是关键信息，长这样：

     启动完成 · 后台控制台: http://127.0.0.1:8787（本机） /
                            http://192.168.1.20:8787（局域网） /
                            http://<服务器IP>:8787（外网）
     登录密钥 (初始): Xk3!qm7Yv2#tRb9Ldz4A
     快捷登录（本机）: http://127.0.0.1:8787/?key=Xk3!qm7Yv2#tRb9Ldz4A
     快捷登录（同一 Wi-Fi 局域网）: http://192.168.1.20:8787/?key=...
     会话：无互动 30 分钟退出 · 自登录起最长 3 小时 · 重启框架需重新登录

这个窗口必须一直开着。关掉窗口 = 关掉机器人。
家用宽带的电脑没有真公网 IP，「外网」那一条通常用不上，忽略即可。

--------------------------------------------------------------------------------
第 5 步：登录后台
--------------------------------------------------------------------------------
1) 直接把「快捷登录（本机）」那条完整链接复制进浏览器，会自动带着密钥登录。
2) 或者打开 http://127.0.0.1:8787 ，手动粘贴「登录密钥」。
3) 首次登录会要求同意协议，然后必须设置自己的密码（初始密钥是随机生成的，
   设过一次密码后就用新密码登录，日志里不再显示明文）。

密钥存放位置：data\auth-key.json
  { "key": "...", "updatedAt": 1700000000000, "kind": "custom" }
  kind = initial 表示还没设过密码，custom 表示已经是你自己设的。

  ▸ 忘记密码怎么办
    关掉服务 → 删掉 data\auth-key.json → 重新 start.bat。
    启动时会生成一个新的初始密钥，直接看控制台输出。

  ▸ 浏览器打开是空白页或一直转圈
    先看控制台有没有「Web UI 未构建」的警告。有就执行 start.bat force。
    再不行按 Ctrl+F5 强制刷新，清掉旧的前端缓存。

  ▸ 提示需要重新登录
    这是设计如此：闲置 30 分钟、或登录满 3 小时、或框架重启，都要重新登录。

--------------------------------------------------------------------------------
第 6 步：接上 QQ（让机器人真的能聊天）
--------------------------------------------------------------------------------
咔咔珂只是框架，还需要一个协议端负责登录 QQ，最常用的是 NapCat。
Windows 上的 NapCat 一般下载 Shell 版或框架版，自己单独启动。

最简单的对接方式是「反向 WebSocket」：
  · 咔咔后台 → 连接 → 添加 → OneBot「反向 WS」，监听端口填 6700
  · NapCat 里添加一个 WebSocket 客户端，地址填 ws://127.0.0.1:6700
  · 两边都启用，咔咔后台的连接卡片变成已连接就成了

详细步骤、其他四种对接方式（正向 WS / HTTP 服务器 / HTTP SSE / HTTP 客户端）、
以及 Docker 场景的地址怎么填，看同目录的 连接教程.txt。

  ▸ 注意 8787 和 6700 是两个不同的东西
    8787 = 咔咔自己的后台控制台端口（在 data\config.json 里配）
    6700 = 反向 WS 的监听端口（在后台的连接里配）
    别把两个填反。

--------------------------------------------------------------------------------
第 7 步：常见报错速查（Windows）
--------------------------------------------------------------------------------
【依赖安装类】

  ▸ npm install exited with code 1 / ECONNRESET / ETIMEDOUT
    原因：网络到 npm 源不通。
    解决：启动脚本已经默认把源切到 https://registry.npmmirror.com。
          若你的网络对该镜像也不友好，可自己指定：
            set KAKAKE_NPM_REGISTRY=https://registry.npmjs.org
            start.bat
          然后重试。挂着代理软件的话，试试关掉「系统代理」再装。

  ▸ 404 Not Found - GET https://nodejs.org/dist/... 之类
    原因：npm 的 registry 被设成了 Node 二进制镜像地址，那里没有 npm 包。
    解决：脚本会自动纠正这种配置并打印「npm registry → ...」。
          若仍失败，执行 npm config delete registry 后重来。

  ▸ EPERM: operation not permitted, rename ...
    原因：杀毒软件/同步盘/资源管理器占着文件。
    解决：退出同步盘与安全软件的实时监控，把项目移出 OneDrive，重试。
          必要时删掉 node_modules 整个文件夹再 start.bat。

  ▸ tsx not found after npm install. Delete node_modules and retry.
    原因：依赖装了一半（常见于中途断网或被杀软拦截）。
    解决：删掉 node_modules 文件夹，重新 start.bat。

  ▸ 卡在 npm install 很久没动静
    首次装依赖本来就慢（几百 MB）。想看进度就用 start.bat verbose。

【构建类】

  ▸ 前端构建报 JavaScript heap out of memory
    原因：内存不足。脚本对 4 GB 及以下内存的机器会自动限堆，但个别情况仍会溢出。
    解决：关掉占内存的程序重试；或临时手工放宽：
            set NODE_OPTIONS=--max-old-space-size=3072
            start.bat force

  ▸ packages/server/main.mjs missing; server build failed
    原因：后端打包（esbuild）失败，真正的错误在上面几行。
    解决：用 start.bat verbose 重跑，看第一条报错。多数是源码改错了。

  ▸ 改了代码但界面没变化
    原因：前端产物还是旧的。
    解决：start.bat force。彻底一点：删掉整个 packages 文件夹再启动，
          它会被完整重建（packages 是纯产物目录，删掉不会丢数据）。

【启动与端口类】

  ▸ 端口 8787 已被占用：先停掉占用它的进程，或改 data/config.json 里的 port
    查是谁占的：
      netstat -ano | findstr :8787
      tasklist | findstr <上一步看到的PID>
    确认不是自己上次没关干净的咔咔后，再决定结束进程或换端口。
    换端口：编辑 data\config.json 的 "port": 8787 → 例如 18787，重启。

  ▸ 没有权限监听端口 xxx（EACCES）
    原因：端口小于 1024，或被系统保留区间占用。
    解决：改成 8787 / 18787 这类高位端口。
    补充：Windows 有个 excludedportrange 机制（常被 Hyper-V/WSL 占用），
          用 netsh interface ipv4 show excludedportrange protocol=tcp 可以看到，
          撞上就换端口。

  ▸ 监听地址 xxx 在本机不存在：改回 0.0.0.0 即可
    原因：config.json 里把 host 写成了一个本机没有的 IP。
    解决：改回 "host": "0.0.0.0"。

  ▸ 同一 WiFi 的手机打不开控制台
    逐条检查：host 是否为 0.0.0.0；防火墙是否放行了 Node.js 的「专用网络」；
    手机和电脑是否在同一个网段（有些路由器开了 AP 隔离）。
    临时验证可用管理员命令行执行：
      netsh advfirewall firewall add rule name="kakake" dir=in action=allow protocol=TCP localport=8787

  ▸ 想直接看日志文件
    log 文件夹里有运行日志；data 文件夹放配置与连接信息。
    这两个目录不要删。

--------------------------------------------------------------------------------
第 8 步：日常怎么用
--------------------------------------------------------------------------------
启动    双击 start.bat（或命令行 start.bat）
停止    在窗口里按 Ctrl+C，或直接关掉窗口
重启    停掉再启一次；改了 data\config.json 必须重启才生效
更新    覆盖新版源码后 start.bat force，让前后端都重新构建
重置产物 删掉 packages 文件夹（可整夹删除）再启动，会自动重建
备份    只需备份 data 和 plugins 两个文件夹（配置、连接、插件都在里面）

想让它开机自启：把 start.bat 的快捷方式放进
  C:\Users\你的用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
（Win+R 输入 shell:startup 可直接打开这个目录。）
注意这种方式需要你登录桌面后才会运行，笔记本合盖睡眠也会中断服务。
要 7×24 稳定运行，建议放到 Linux 服务器上（见 03-Linux 使用教程.txt）。

--------------------------------------------------------------------------------
附：目录与开关速查
--------------------------------------------------------------------------------
【目录】
  data\             配置与运行数据（config.json、auth-key.json、connections.json…）
  log\              运行日志
  plugins\          安装的插件
  plugins_two\      按账号隔离的插件运行副本
  src\              源码（src\web 是前端源码）
  packages\         构建产物（web + server），可整夹删除、自动重建
  使用教程\         本教程与连接教程、插件开发教程

【data\config.json 常改项】
  "host": "0.0.0.0"     监听地址，一般不用改
  "port": 8787          后台端口，冲突时改这里
  "logLevel": "info"    日志级别，排查问题可改 debug
  "apiTimeoutMs": 120000  调用协议端接口的超时（毫秒）

【环境变量开关（临时排查用，cmd 里 set XXX=1 后再启动）】
  KAKAKE_FORCE_WEB_BUILD=1    等价于 start.bat force
  KAKAKE_VERBOSE_BOOT=1       等价于 start.bat verbose
  KAKAKE_NPM_REGISTRY=...     指定 npm 源
  KAKAKE_BOOTSTRAP_DRY_RUN=1  只检查依赖和构建，不真的启动服务
  KAKAKE_NO_WEB=1             不托管 Web 控制台（只跑机器人后端）
  KAKAKE_PUBLIC_HOST=...      手动指定对外 IP/域名（影响日志里的公网地址）
  KAKAKE_DNS_RESULT_ORDER=ipv4first   出现 fetch failed 时可试，强制优先 IPv4
