# TypeScript 轨：源码开发 → Vite 构建 → 整夹装载

这一轨对齐「其他插件源码」的标准做法，业务逻辑和 JavaScript 轨一样：

- **精准匹配**指令再做事（`if (text === '你好') { … }`）
- 多条指令：`你好` / `帮助` / `ping`，以及群聊 `禁言 QQ号 秒数`
- 用 `ctx.actions.call(接口名, 参数)` 调协议（发消息、禁言同通式）
- 先看**分步例子**代码窗，再改源码、构建、装载

更完整的名词表见页面上方的**前言**。

## 阅读标记

| 标记 | 含义 |
|------|------|
| 【照抄】 | 第一次做直接复制即可 |
| 【核心】 | 要看懂；加指令就照着再写一个 `if` |

## 几个词（白话）

| 写法 | 人话 |
|------|------|
| `if (条件) { … }` | **如果**条件成立，**就**做大括号里的事 |
| `===` | 两边**一模一样**才算对 |
| `function` / `async function` | 给一小段步骤起名字，可反复调用 |
| `ctx.actions.call(接口名, 参数)` | **调协议端任意接口**的通式 |

## 收消息 / 发消息：只用 JSON，不要 CQ

| 做法 | 对不对 |
|------|--------|
| 从 `event.message`（JSON 消息段数组）里取文字 | 推荐 |
| 发送时用 `[{ type: 'text', data: { text: '…' } }]` | 推荐 |
| 用 `raw_message` 或 `[CQ:…]` 字符串 | **不要** |

## 一、两棵目录树

### 1）源码工程（你写代码、执行构建）

`使用教程/插件开发/TypeScript/hello-src/`

```text
hello-src/
  package.json / plugin.json / tsconfig.json / vite.config.ts
  src/index.ts
  kakake-plugin-hello/     ← npm run build 后生成的产物夹
    package.json
    plugin.json
    index.mjs
```

### 2）装进咔咔（只拷产物夹）

```text
plugins/kakake-plugin-hello/
  package.json
  plugin.json
  index.mjs
```

**不要**只拷一个 js；**不要**把整个 `hello-src`（含 node_modules）当插件装。

---

## 二、依赖与构建

进入 `hello-src/`：

```bash
npm install
npm run build
```

- `npm install`：拉取 `vite`、`typescript` 等构建工具  
- `npm run build`：生成 `kakake-plugin-hello/` 三件套  

检查产物夹里是否有 `package.json`、`plugin.json`、`index.mjs`。  
然后把**产物夹**拷到 `plugins/kakake-plugin-hello/`。

改了 `src/index.ts` 后必须再 build，再覆盖产物夹。

## 三、指令表

| 对方发送 | 机器人做什么 |
|----------|--------------|
| `你好` | 回复 `你好呀` |
| `帮助` | 回复可用指令列表 |
| `ping` | 回复 `pong` |
| `禁言 QQ号 秒数` | 调用 `set_group_ban`（仅群聊；机器人需有管权限） |

## 四、怎么阅读下面的代码窗

1. **分步 ①～⑥**：每一块只讲一件事（和 JS 轨同逻辑）。  
2. **分步 ⑥**：`ctx.actions.call` 通式 + 禁言 `set_group_ban`。  
3. **源码配置**：`package.json` / `plugin.json` / `tsconfig` / `vite.config`（【照抄】）。  
4. **完整源码 `src/index.ts`**：可运行的整份（装载前要先 build）。  
5. **产物三件套**：构建生成，一般不用手改；真正拷进 `plugins/` 的是这一夹。

### 源码 `package.json` / `plugin.json` 要点

- `main` 与 `entry` 都是产物里的 `index.mjs`  
- 改插件名时：文件夹名、`name`、两处 json 一起改  

### `vite.config.ts` 要点

- `outDir: 'kakake-plugin-hello'` → 产物文件夹名  
- 打包 `src/index.ts` → `index.mjs`  
- 构建结束时把两个 json 写入产物夹  

---

## 五、装好怎么测

总开关开 → 连接子开关开 → 发 `你好` / `帮助` / `ping`；群里可试 `禁言 <QQ> 10`（需管权限）。
